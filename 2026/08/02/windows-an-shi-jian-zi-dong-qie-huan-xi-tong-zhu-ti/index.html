Windows 按时间自动切换浅色与深色模式

发表于2026-08-02|更新于2026-08-06|技术
|阅读量:

Windows 的浅色和深色模式可以通过注册表控制。下面这组脚本把主题切换、计划任务安装和卸载组合在了一起，不需要额外软件。

它做了什么

  • 登录 Windows 时检查一次当前时间；
  • 每天 08:00 自动切换为浅色模式；
  • 每天 23:00 自动切换为深色模式；
  • 核心脚本支持 light、dark 和 auto 三种模式，计划任务使用 auto；
  • 所有任务只作用于当前用户。

auto 模式的规则是：07:00 到 22:59 使用浅色模式，其余时间使用深色模式。

使用方法

把下面 6 个文件放在同一个目录，双击 install-windows-theme-tasks.bat 即可安装或更新计划任务。任务会被创建到 WindowsThemeSwitch 任务文件夹下。

计划任务不会直接调用 cmd.exe 或 set-windows-theme.bat，而是通过 wscript.exe 隐藏启动 run-windows-theme-hidden.vbs，再由它调用 PowerShell，因此执行时不会弹出控制台窗口。

卸载时双击 uninstall-windows-theme-tasks.bat。如果移动了脚本目录，需要重新安装任务，因为计划任务保存了脚本的绝对路径。

修改切换时间

windows-theme.ps1 里的 $lightModeStartHour 和 $darkModeStartHour 是 auto 模式自己的判断边界。当前规则是 07:00 到 22:59 使用浅色，23:00 之后使用深色；如果修改夜间时间，还要同步修改 $darkModeStartHour。修改后重新运行安装脚本，计划任务才会更新。

下载

不想手动复制文章中的代码，可以直接下载：

下载 ZIP 后解压到同一个目录，再运行安装脚本即可。

文件说明

  • windows-theme.ps1：写入当前用户的主题注册表，并通知 Windows 刷新设置。
  • run-windows-theme-hidden.vbs：使用隐藏的 wscript.exe 启动 PowerShell，避免计划任务弹出窗口。
  • manage-windows-theme-tasks.ps1：创建或删除 3 个计划任务，并设置任务的触发时间。
  • install-windows-theme-tasks.bat：执行安装。
  • uninstall-windows-theme-tasks.bat：执行卸载。

set-windows-theme.bat 仍保留在项目下载包中作为兼容文件，但不再是计划任务的执行入口，本文不再介绍手动执行方式。

完整源码

windows-theme.ps1

run-windows-theme-hidden.vbs

manage-windows-theme-tasks.ps1

install-windows-theme-tasks.bat

uninstall-windows-theme-tasks.bat

注意事项

这些任务使用当前用户的交互式登录会话运行，不会替其他 Windows 用户切换主题。脚本还会调用 Windows PowerShell 和 user32.dll 刷新设置，因此适用于 Windows 环境，不适用于 Linux 或 macOS。
